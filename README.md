# GRAFIPLOT NUMERADOR A4

Aplicación de escritorio para Windows para superponer numeración secuencial sobre imágenes y PDF, con salida PDF tamaño A4 vertical u horizontal.

## Descargar

Entra a [Actions](https://github.com/vasquezpalparoy-star/GRAFIPLOT-NUMERADOR/actions), abre la última ejecución de **Compilar EXE Windows** y descarga el artefacto `GRAFIPLOT_NUMERADOR_A4_WINDOWS`. Descomprime el ZIP para obtener `GRAFIPLOT_NUMERADOR_A4.exe`.

## Funciones

- Prefijo configurable, valor inicial y cantidad de ceros.
- Arrastrar posición, configurar color y tamaño.
- Zoom para vista previa sin alterar las medidas físicas A4.
- PDF o imagen de fondo, centrado sin deformar.
- PDF A4 consecutivo listo para imprimir.

El flujo `.github/workflows/compilar-windows.yml` compila automáticamente el ejecutable al recibir nuevos cambios en `main`.
